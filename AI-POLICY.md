# AI Policy

## e-cloudstream fork policy

Read and follow [AGENTS.md](AGENTS.md) before implementation, especially the mandatory upstream-sync procedure. This is an independent, website-specific fork directed by @mohamedyassine-benmiled. Do not create upstream pull requests as a default contribution path; local contributions belong here unless the maintainer explicitly directs otherwise. Preserve upstream attribution and licensing, protect user data/work, and never commit secrets. Disclose test limitations and do not claim phone/TV acceptance from unit tests.

## Inherited upstream principles

AI is a great tool. However, we want you to follow these rules regarding usage of AI in order to ensure the quality of both code and discussions.

1. Always state any AI usage in pull requests and issues. 

2. Always test code before making a pull request. We do not want to test your AI generated code. 

3. Listen to humans over computers. Contributors to CloudStream know this codebase better than an AI. 

4. You should be able to explain and fix any code you submit. We do in-depth reviews and will reject low effort contributions.
